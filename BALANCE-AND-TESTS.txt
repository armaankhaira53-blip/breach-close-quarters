from any weapon slot. Max 190 damage, 6m radius, falloff/cover; no refund on detonation.
HUD and shop supply rules state the controls and active count. Paused use is rejected.

OTHER COMBAT/MODEL FIXES
Sniper pierces sorted unique enemies along the pre-recoil shot ray, stopping at solid
map geometry. Base body damage is 90; previous 115 x 2.4 = 276 headshot is retained
explicitly. Existing long-distance falloff and armor/shield rules remain.
K9: one local skeleton for body, articulated legs/paws, muzzle, ears, harness, eyes
and tail. Shared heading/knockdown/hurt/attack/death transforms and matching bounds;
a whole-body death fall replaces disappearing into particles. Corpse cap 12 / 12s life.
Glock and revolver: separate open sights, centered reflex views with foreground
geometry hidden during aim, pre-recoil shot ray, normal return to hip view.
RPG: removed the two side-mounted box/button parts. Tube, rocket, grips and reload
attachments preserved. Main-menu wave-credit explanation removed; compact difficulty
summary remains. Actual payouts and in-wave reward notifications remain unchanged.
Nuke (existing public sandbox): visible falling physical model, impact-triggered
map flash and large fireball with synthesized explosion audio. Clears all enemies
as before. Fireball lasts 3s; flash decays; menu/death clears state and normal lighting.
Invincibility (sandbox only): shared player damage guard, visible state, reversible
toggle, resets on death/redeploy/menu. Sandbox actions never write the normal save.

STATISTICS AND SAVES
Total Waves increments once at final credited elimination, before same-frame death;
wave identifier guard prevents timer/menu duplicates. Total Eliminations increments
once per player-credited enemy death; enemy-caused explosions do not award eliminations.
Practice/sandbox do not write combat progress. Personal Stats reads the current normal
profile so failed disk writes cannot hide earned in-session statistics. Unreadable save
bytes are preserved instead of silently overwritten by defaults. Fresh simulation
sessions reload the same valid collection/totals/unknown fields.
Existing game saves are browser-local; moving origin/browser requires the existing
export/merge backup controls. No account/cloud migration or reset was performed.
